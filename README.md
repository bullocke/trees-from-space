# Trees from Space

Beginner-friendly tutorials for accessing, visualizing, and analyzing remote sensing data for ecological research.

Trees from Space helps graduate students, faculty, and other researchers bring satellite and airborne observations into their own work. The lessons focus on vegetation, forest structure, carbon, disturbance, and environmental conditions around study sites. Each lesson starts from one research question, uses one primary data access route, and ends with a small result you can reproduce and adapt.

The lessons assume basic familiarity with Python or R and little or no remote sensing experience. The University of Utah Center for High Performance Computing (CHPC) is the primary execution environment. Google Colab and a local Jupyter or VS Code setup also work where a lesson says so.

## Quick start

1. Read [Notebook basics](docs/getting-started/notebook-basics.md) if Jupyter is new to you.
2. Create a free [NASA Earthdata Login](docs/getting-started/earthdata-login.md) account.
3. Set up an environment on [CHPC](docs/getting-started/chpc.md), in [Colab](docs/getting-started/colab.md), or on your [own computer](docs/getting-started/local.md).
4. Run the [getting-started notebook](tutorials/getting-started/) to check your setup, then choose a lesson from the [tutorial index](tutorials/README.md).

## Tutorials

The [tutorial index](tutorials/README.md) lists every lesson with its languages, prerequisites, resource needs, and the platforms on which it was last tested. Lessons are added one dataset or workflow at a time.
